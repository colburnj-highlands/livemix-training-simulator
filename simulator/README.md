# Simulator delivery

`index.html` is the public simulator with embedded artwork, styles, training
configuration, and application code. Practice mixes use browser local storage.

The header’s **Lock** link points to `../index.html`, the PIN lock screen.
Preserve that link when manually replacing the simulator with an approved update.
Keep existing storage keys stable, then rebuild and check navigation and saved mixes.
See the root README for preview and deployment instructions.
